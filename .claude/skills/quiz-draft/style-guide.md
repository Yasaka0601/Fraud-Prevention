# 詐欺対策道場 クイズ作成ガイド

## 1. 出題方針（いちばん大事）
世の中の詐欺クイズは「怪しい電話 → 電話を切る」のように、知識がなくても常識で解けるものが多い。
このアプリでは次の3つを必ず守る。

1. **手口を知ることに焦点を当てる**
   - 「どう対応するか」より「犯人は次に何を言う／何をするか」「なぜその言い回しを使うか」「どんな仕組みで被害になるか」を問う
2. **知識がなければ解けない問題にする**
   - 怪しい選択肢を消していけば正解が残る、という消去法を通用させない
   - 正解だけが丁寧・安全そうな言い回しにならないよう、選択肢の長さと口調をそろえる
   - 「電話を切って家族に相談」「無視する」のような、誰でも選べる正解を作らない
3. **つい間違えてしまう問題にする**
   - 不正解の選択肢は「よくある思い込み」「半分だけ正しい知識」「本物でもありそうな話」で作る
   - 「これなら本物だろう」と思わせる材料（本物の番号・身分証・長いやり取り など）を問題文に入れる

## 2. 真似する良い例（既存クイズより）
| 元ID | タイトル | 良い理由 |
|---|---|---|
| 96 | 適用罪名について | 「だまして盗る＝詐欺罪」という思い込みを突く。正解は窃盗罪 |
| 30 | キャッシュカード手交型（切り込み） | 「切り込みを入れれば使えない」と思わせる、受け子の具体的な動きを問う |
| 37 | 警察署の代表番号 | 「番号を調べたら本物だった」という安心材料を入れている（番号は偽装できる） |
| 10 | 警察官はどれ？ | 「ビデオ通話で手帳」「折り返し番号」など、本物っぽい判断材料を並べて区別させる |
| 65 | ロマンス詐欺（ビデオ通話） | 「詐欺ではないと誤って判断する理由」を選ばせる、逆向きの問い方 |
| 79 | クレジットカード不正利用に必要な情報 | 「セキュリティコードがあれば安全」という思い込みを崩す |

## 3. 真似しない例
- 元ID 1・2・6 など：「電話を切って自分でかけ直す」以外の選択肢が明らかに危ないため、常識だけで解ける
- 「〇〇とは？」の用語問題で、正解以外の説明がでたらめすぎるもの → 不正解もその用語と取り違えやすい別の用語の説明にする

## 4. 形式のルール
- **タイトル（name）**：50文字以内（モデルのバリデーション）。「手口名（場面）」の形が多い。例：「還付金詐欺（年金一部未払い）」
- **問題文**：
  - 場面を設定して、犯人のセリフは「」で1行ずつ書く
  - 最後の問いかけの形：「この後に続く詐欺の手口を選択してください」「不審な点を選択してください」「〜として正しいものはどれ？」「〜として誤っているものを選択してください」
  - 複数正解のときだけ「（複数回答可能です）」と書く。正解が1つの問題には書かない（アプリの仕様で、複数回答可能は複数正解のクイズだけ）
  - 時期によって変わる情報は「※ 2026年 1月 現在」のように時点を書く
- **選択肢**：基本は4択（3〜5択も可）
  - 正解は1つでも複数でもよい（既存は約半数が複数正解）
  - 正解の位置をばらす（既存は1番目に偏っているため）
- **解説**：
  1. 事実の言い切り（例：「警察官はビデオ通話で警察手帳を提示しません」）
  2. 手口の狙いや仕組み（なぜだまされるのか）
  3. 間違えやすかった選択肢がなぜ違うか
  4. 必要に応じて正解の言い直し
  5. 最後に出典（下の形式）
- **解説は、出典を開かなくても理解できるように書く**
  - 専門用語（例：DMARC、ユーザー補助、サブドメイン）は、最初に出てきたところで一言で説明する。たとえ話を使ってよい
  - 「出典の手順3」「チラシのとおり」など、出典を見ないと分からない書き方をしない
  - 数字は「何のうち何%か」を書き、「約3通に1通」のように言い換える
  - 不正解の選択肢は、1つずつ「なぜ違うか」を書く
  - 出典の中で大事な事実（背景・理由など）は、要約して解説に入れる
- **解説は端的に書く**
  - 1文は短く。1つの段落・箇条書きは2文まで
  - 長くなる場合は【〇〇とは】【ほかの選択肢が違う理由】のように見出しで区切る
  - 「なぜ違うか」は箇条書きで、選択肢ごとに1〜2文
  - 用語の説明だけで長くなる場合は、その用語を問う別の問題に分けることを提案する
- **出典の書き方**：
  ```
  出典：大阪府警察
  URL：https://...
  ```
  画像を他のサイトから使う場合は「画像出典：〇〇 URL」と書く
- **カテゴリ**（既存から選ぶ）：不審電話 / WEB / SNS / メール / 詐欺の制度・用語 / 詐欺対策道場・極（最難問）。複数付けてもよい
- **コース**：既存コース（各5問）に合えば候補を書く。合わなければ「新コース案：〇〇」と提案する。5問を超えて入らない問題は「なし（余った問題）」としてDBに残し、あとで余った問題同士でコースを作る
- **ポイント（1〜10）の目安**：
  - 1〜3：用語や制度の基本
  - 4〜6：手口の流れを知っていれば解ける
  - 7〜8：思い込みを突く問題、複数正解
  - 9〜10：法律・技術の深い知識や、ほとんどの人が間違える問題
- **画像**：既存で画像付きは6問のみ（偽の警告画面・偽の身分証など）。必要なら「画像案：〇〇の画面」と文章で書く（画像はClaudeが作らない）

## 5. 既存のテーマの偏り（新しい問題で補いたいところ）
- 多い：不審電話（41問）、特にニセ警察官・還付金・キャッシュカード
- 少ない：メール（10問）、SNS（13問）。SNS型投資・ロマンス・ClickFix 以外の新しい手口は少ない
