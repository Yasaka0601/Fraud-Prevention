# 詐欺対策道場とは？
「おばあちゃん、おじいちゃん、詐欺に気をつけてやー」\
「変な電話がかかってきたら、すぐ言うてやー」\
あなたは、このような声掛けだけで終わっていませんか？

漠然とした声がけだけでは、大切な家族は守れません。\
**詐欺対策道場**は、家族ぐるみで詐欺に備えるクイズアプリです。
- クイズで詐欺の手口を楽しく学べる
- 家族ルームでクイズの成績を共有、知識レベルを把握できる
- クイズを解き、ポイント・バッジを獲得し、継続学習をサポート



# このアプリを作ったきっかけ

ある日、離れて暮らす両親から電話がありました。

「警察から電話があって、お母さんの口座が使い込まれているって言われた。」\
「資産状況も聞かれたんだけど…これって大丈夫かな？」

私はすぐに「それは詐欺だ」と気づき、両親に伝えました。

しかし、そのとき、はっとしました。

**「両親の防犯意識が高いというのは、私の思い込みだったのでは？」**

両親が実際にどれくらい詐欺の手口を知っているのか\
離れて暮らす私には、まったく分かっていませんでした。

「家族の詐欺への理解度を把握できれば、離れていても安心できる」\
そう感じたことが、このアプリを作るきっかけになりました。

# 特殊詐欺発生状況について

警察庁が公表した最新の統計では、特殊詐欺の被害は深刻化しています。

**令和７年における特殊詐欺認知件数**
- 認知件数：27,758件（ 前年比 ＋6,715 件、＋31.9%）
- 被害総額：約 1,414.2億円（ 前年比 ＋695.4 億円、＋96.7%）

[警察庁・SOS47 特殊詐欺対策ページ](https://www.npa.go.jp/bureau/safetylife/sos47/new-topics/260213/03.html)

過去最悪だった前年をすでに大きく上回るペースで増加しています。\
もはや漠然とした知識では詐欺を防ぐことはできません。\
注目すべきは **ニセ警察詐欺** による被害が顕著という点です。\
これはまさに、私の両親が経験した手口でもあります。

被害を食い止めるには、「知識」を身につけることが何より重要です。

# 制作にあたって
## クイズコンテンツの設計
世間に存在する詐欺クイズの多くは「詐欺である・詐欺ではない」の2択形式が主流です。\
しかし、詐欺を防ぐには「手口を知ること」が何より重要だと考えました。

本アプリのクイズは「この後に続く詐欺の手口は？」という形式を中心に、\
3択・4択で構成しています。回答後に手口や対処法を解説することで、\
**「なんとなく気をつける」から「手口を知って防ぐ」** へと意識が変わることを目指しました。

## 競い合いながら楽しく学べる仕組み
詐欺対策の学習は、一度やって終わりでは意味がありません。\
継続して学び続けてもらうために、以下の3つの仕組みを実装しました。

- **ポイント機能**：クイズ正解でポイントが付与される
- **ランキング機能**：ポイントでユーザー同士が競い合える
- **バッジ機能**：学習の節目に称号が獲得できる
