# 詐欺対策道場とは？
「おばあちゃん、おじいちゃん、詐欺に気をつけてやー」\
「変な電話がかかってきたら、すぐ言うてやー」\
あなたは、このような声掛けだけで終わっていませんか？

漠然とした声がけだけでは、大切な家族は守れません。\
**詐欺対策道場**は、家族ぐるみで詐欺に備えるクイズアプリです。
- クイズで詐欺の手口を楽しく学べる
- 家族ルームでクイズの成績を共有、知識レベルを把握できる
- クイズを解き、ポイント・バッジを獲得し、継続学習をサポート



# このアプリを作ったきっかけ

ある日、離れて暮らす両親から電話がありました。

「警察から電話があって、お母さんの口座が使い込まれているって言われた。」\
「資産状況も聞かれたんだけど…これって大丈夫かな？」

私はすぐに「それは詐欺だ」と気づき、両親に伝えました。

しかし、そのとき、はっとしました。

**「両親の防犯意識が高いというのは、私の思い込みだったのでは？」**

両親が実際にどれくらい詐欺の手口を知っているのか\
離れて暮らす私には、まったく分かっていませんでした。

「家族の詐欺への理解度を把握できれば、離れていても安心できる」\
そう感じたことが、このアプリを作るきっかけになりました。

# 特殊詐欺発生状況について

警察庁が公表した最新の統計では、特殊詐欺の被害は深刻化しています。

令和７年における特殊詐欺認知件数
- 認知件数：27,758件（ 前年比 ＋6,715 件、＋31.9%）
- 被害総額：約 1,414.2億円（ 前年比 ＋695.4 億円、＋96.7%）

参考リンク
[警察庁・SOS47 特殊詐欺対策ページ](https://www.npa.go.jp/bureau/safetylife/sos47/new-topics/260213/03.html)

過去最悪だった前年をすでに大きく上回るペースで増加しています。\
もはや漠然とした知識では詐欺を防ぐことはできません。\
注目すべきは **ニセ警察詐欺** による被害が顕著という点です。\
これはまさに、私の両親が経験した手口でもあります。

被害を食い止めるには、「知識」を身につけることが何より重要です。

## ユーザーの獲得について
- 検索エンジンで「特殊詐欺」「防犯アプリ」「家族 見守り」などのキーワードで上位表示を狙うSEO対策をします。

- RUNTEQ内コミュニティでの初期導入を想定しています。
## サービスの差別化ポイント・推しポイント
特殊詐欺のクイズを出題しているWebサイトは、警察のホームページをはじめとし、多数存在しています。\
しかし、本アプリは３点の差別化ポイントがあります。
- １点目は「詐欺知識の習得状況を可視化すること」です。\
ポイント制、ランキング制を導入することによって、どれくらい知識が身についているのかを測れるという点です。
- ２点目は「クイズの成績を家族に共有すること」です。\
祖父、祖母がどれくらいの成績なのか、家族全員で共有することができます。\
そうすることにより、具体的な詐欺の対策を行うことができます。
- ３点目は「情報提供およびクイズ投稿機能」です。（本リリース機能）\
アプリ利用者の皆さんで、クイズを作成し、アプリ制作者による審査に通過すれば、クイズを投稿することが出来ます。\
また、いただいた情報を基に、アプリ制作者がクイズを作成します。\
詐欺の手口は、日々、巧妙化、複雑化していることから、皆様の実体験や、得た最新情報が貴重な情報資源となります。
## 機能候補
本アプリの機能は、３つの軸を中心に実装します。
### ３つの軸
1. クイズ機能と結果の共有
2. 直感で使えるアプリ（UI/UXデザイン）
3. 高齢者がアプリを簡単に使用する導線の確保（簡単な招待機能など）


**MVPリリーズ機能**
- ホストユーザー登録機能
　Googleログイン機能
　メールアドレスによる認証
- 子ユーザー登録機能
　高齢者向けに、ホストユーザーが作成した子ユーザーによる簡単ログイン。\
「家族ルーム名」と「合言葉」のみでログイン可能にする。\
ルームに参加すると、名前を入力し、子ユーザーを登録する。
- ルーム招待機能
メール,SMSで招待文を送る（URL）による招待。\
本文にはURLと、家族ルーム名、合言葉が記述されており、家族ルームの参加方法が丁寧に記述されている。
- 家族ルーム機能\
各ユーザーの採点履歴の閲覧および共有。　
- クイズ機能\
不審電話コース
- 高齢者に配慮したUI/UX設計。
- スマートフォンでの使用を想定したレスポンシブデザイン
- ポイント機能\
クイズに正解するとポイントが加算。

**本リリース機能（上から順に優先して実装予定）**
- アプリ使用までの導線のさらなる簡略化
1. LINE招待機能
2. ガワネイティブ化

- 情報投稿\
「このような不審電話が流行っている」などの断片的な情報を募集。\
提供していただいた情報を元に新たなクイズを作成。
- クイズ投稿機能\
ユーザーがクイズを投稿する。\
クイズが実装されたら、クイズに作成者名が併記される。
- ランキング機能\
家族ルーム内のランキングと、家族ルーム単位でのランキングの両方を閲覧することが出来る。\
他の家族とポイントを競い合いましょう。
- クイズ再挑戦機能\
間違えた問題をまとめたコース
- クイズコースの追加\
　不審メールコース\
　偽サイトコース\
　SNSコース\
　激ムズコース
- クイズ正解率機能
- 称号機能
- X 投稿機能
